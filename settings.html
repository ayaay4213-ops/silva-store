تصاميم رقمية أنيقة ومميزة

بعد تنزيل الملفات، افتحي مستودع GitHub ثم ارفعي الصور إلى المجلد الرئيسي، واستبدلي ملف site-settings.json بالإعدادات الجديدة. لا ترفعي ملفات HTML أو SVG كصور.

طريقة نشر التعديلات على المتجر

  1. اضغطي تنزيل صورة الواجهة و/أو صورة الخلفية.
  2. اضغطي تنزيل إعدادات التصميم لحفظ ملف JSON.
  3. في GitHub افتحي مستودع silva-store واختاري Add file ثم Upload files، وارفعي الصور إلى المجلد الرئيسي.
  4. افتحي site-settings.json واستبدلي محتواه بمحتوى الملف الذي نزّلتيه، ثم احفظي التغييرات.
  5. انتظري تحديث GitHub Pages وافتحي الموقع من جديد.
